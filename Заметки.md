Мобильное/Веб приложение для студентов колледжа - Narxoz College - NC
Включает в себя базовые функции журнала + 
Роли: 
Студент, 
Преподаватель, 
Директор,
Админ - в их счет входит Управляющие лица, Уполномоченные на административные действия лица по типу работников обслуживания самого заведения или данной электронной системы.

Студент - 

Навигационная панель - 
Главная, Учебный процесс, Социум, Профиль

Главная страница - 
Новости и мероприятия заведения списком по заголовком с описанием и фото, все эти вещи находятся только на главной странице и не будут требовать их открытия в новой странице. Будет функция поиска из этого, либо с помощью даты, либо же по словам.

Учебный процесс - 
Вкладки:
Журнал оценок по дням
Статус студента относительно кредитов, летнего семестра, задолженностей по учебе
Расписание + предписанные к парам дополнения/ уведомления/ домашние задания
Транскрипт/ GPA
Регламент обучения - академический календарь с прикрепленным силлабусом
Преподаватели
Учебные материалы/ онлайн библиотека + указание есть ли данные книги в физическом экземпляре, с указанием кто взял книгу, или указание книги на счету у студента/другого участника учебного процесса, функция забронировать
Связаться по учебным вопросам/техподдержка

Социум - 
Вкладки:
Общедоступный форум - для обсуждения разных тем, для их начала - создается тема рассуждения которая появляется на странице форума и уже переходя на него можно отвечать, можно и общаться на счет мероприятий, своих тем, хобби, есть возможность писать анонимно(только в форум), это РЕАЛИЗАЦИЯ СОЦИУМА.
Чаты - Общий чат для всех студентов,Личные чаты с преподавателями/ студентами/ другими участниками + групповые чаты для проектов, мероприятий, студклубов по интересам и других общественных процессов.
Карта здания для эвакуации/ навигации.
Лента предстоящих событий

Профиль - 
Информация студента(+статус)
Мои файлы - файлы для хранения для студента, можно создать папки которыми можно и поделиться по типу портфолио, ограничение 2 гб на участника
Смена пароля/ номера
Язык интерфейса
Выйти из аккаунта
