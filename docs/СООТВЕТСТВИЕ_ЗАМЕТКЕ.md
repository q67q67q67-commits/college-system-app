## Итог

- **Реализовано полностью по Заметке:** роли, навигация, главная с событиями и поиском, журнал оценок, расписание с ДЗ, GPA/транскрипт, регламент (страница + материалы к парам), библиотека с бронированием, форум с анонимностью, общий чат, карта (страница), события (лента + CRUD для директора/админа), профиль директора (имя, контакты, «Написать директору»), файлы 2 ГБ, смена пароля/номера, выход, Flutter + веб, адаптив, псевдо-база.
- **Реализовано частично или заглушкой:** статус по кредитам/задолженностям (можно добавить API и экран), список преподавателей (есть в расписании), «связаться/техподдержка» (общий чат), градация оценок (оценки числом есть).
- **Не реализовано (известные ограничения):** личные и групповые чаты, комментарии и вложения к событиям, папки и портфолио в «Мои файлы», посты директора с закреплением, переключение языка интерфейса, пуш-уведомления, «запросы по мероприятиям».

Для производственного использования при необходимости можно доработать пункты из раздела «Не реализовано» и «Реализовано частично».
