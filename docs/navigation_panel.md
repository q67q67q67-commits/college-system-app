# ОБЩИЕ ПРИНЦИПЫ ПРИЛОЖЕНИЯ

* Приложение используется **всеми участниками колледжа**
* Роли пользователей:

  * Student (Студент)
  * Teacher (Преподаватель)
  * Director (Директор)
  * Admin (Администратор системы)
* Интерфейс:

  * Главная страница — **карточная лента**, визуально похожая на главную страницу **kino.kz**
  * Все элементы главной страницы **разделены на независимые блоки**
  * Каждый блок кликабелен и ведёт на **соответствующую подробную страницу**
* Расписание:

  * Отображается **в формате календаря** (аналогично Platonus)
* Технологии:

  * Backend: **Go (Golang)**
  * Frontend: **Flutter**
* Медиа:

  * Вставка изображений, видео и документов должна быть **без жёстких ограничений UI**
  * Управление медиа — через отдельный слой (загрузка, удаление, предпросмотр)

---

# STUDENT ACCOUNT (СТУДЕНТ)

## 1. Main Page (Главная страница)

Содержит следующие **независимые блоки**:

1. **Новости колледжа**

   * Лента официальных новостей
   * Переход к полной новости по нажатию

2. **Профиль директора (preview)**

   * Аватар
   * Имя
   * Краткое описание
   * Переход на полноценную страницу профиля директора

3. **Текущая информация о занятиях**

   * Мини-вид сегодняшнего расписания
   * Если занятий нет — сообщение «Сегодня выходной»
   * При нажатии → открывается полная страница расписания

---

## 2. Учебный процесс

### 2.1 Расписание

* Отображение в виде **календаря**
* Возможность переключения:

  * день / неделя
* Отображаемая информация:

  * предмет
  * преподаватель
  * аудитория
  * тип занятия

---

### 2.2 Журнал

* Просмотр оценок
* Фильтрация по предметам
* Только режим просмотра (без редактирования)

---

### 2.3 Файлы

* Возможности:

  * Создание папок
  * Загрузка файлов (до 2 ГБ)
* Видимость:

  * Private — только студент
  * Shared — доступ по разрешению
* Преподаватели могут:

  * Создавать общие папки
  * Давать доступ конкретным группам

---

### 2.4 Регламент

* Раздел для официальных документов
* На первом этапе:

  * либо пустой
  * либо файлы (академический календарь с сайта Narxoz)
* Только чтение

---

### 2.5 Чаты

Типы чатов:

1. **Чаты с преподавателями / администрацией**

   * Инициация чата → запрос
   * Студент может отправить **не более 2 сообщений до одобрения**
   * Получатель может:

     * принять запрос
     * отклонить запрос

2. **Групповые чаты**

   * Чат учебной группы
   * Чаты по предметам с преподавателем

---

## 3. Студенческая жизнь

### 3.1 События и новости

* Студент:

  * не может добавлять события
  * может просматривать
* Исключение:

  * если студент — **head студенческого клуба**
* Поддержка медиа:

  * изображения
  * видео
  * документы

---

### 3.2 Клубы

Список клубов (фиксированный):

* Narxoz Team
* Debate Club
* ReadingNook
* CarpeDiem
* Art Club
* Star-Guys
* Artox
* Narxoz Ashyq Zhurek

Функциональность:

* Просмотр списка клубов (для всех студентов)
* Отдельная страница клуба:

  * описание
  * медиа
  * участники
* Кнопка **«Хочу присоединиться»**

  * отправляет запрос head’у клуба
* Head клуба:

  * администратор клуба
  * управляет участниками
  * может публиковать события
* По логике:

  * структура похожа на **Telegram-каналы / Discord-серверы**

---

### 3.3 Форум

* Доступен всем ролям
* Возможности:

  * анонимные и неанонимные темы
  * комментарии под темами
  * прикрепление:

    * фото
    * видео
    * документы

---

### 3.4 Профиль директора

* Формат как Twitter:

  * аватар
  * описание
  * лента постов и новостей от директора

# TEACHER ACCOUNT (ПРЕПОДАВАТЕЛЬ)

## Отличия от студента:

* Нет доступа к студенческим клубам как участник
* Есть управление журналами и файлами

## 1. Main Page

Аналогично студенту, но:

* Текущие занятия отображаются **по группам преподавателя**

---

## 2. Учебный процесс

### 2.1 Журнал

1. Страница списка:

   * предметы
   * группы
2. Детальная страница:

   * таблица:

     * строки — студенты
     * столбцы — даты и типы занятий (лекция, практика, СРСП)
   * возможность редактирования оценок

---

### 2.2 Список студентов

* Выбор группы
* Таблица:

  * №
  * ФИО
  * Email

---

### 2.3 Файлы

* Создание папок
* Загрузка файлов (до 2 ГБ)
* Назначение доступа группам

---

### 2.4 Чаты

* Запросы от студентов
* Одобренные чаты
* Групповые чаты

---

## 3. Студенческая жизнь

* События и новости — **может добавлять**
* Форум — участие
* Профиль директора — просмотр

---

## 4. Профиль преподавателя

* Аватар
* ФИО
* Кафедра
* Телефон (конфиденциально)
* Смена пароля и номера

# DIRECTOR ACCOUNT (ДИРЕКТОР)

## Основная роль

* Публичное лицо колледжа
* Контроль контента и новостей

## Возможности:

* Публикация:

  * официальных новостей
  * обращений
  * постов
* Управление событиями колледжа
* Просмотр:

  * форум
  * отчёты активности
* Одобрение:

  * ключевых объявлений
* Имеет публичный профиль (как Twitter)

---

# ADMIN ACCOUNT (АДМИНИСТРАТОР)

## Полный системный доступ

### Возможности:

1. Управление пользователями:

   * блокировка
   * удаление
   * смена ролей

2. Модерация форума:

   * удаление некомпетентных постов
   * скрытие комментариев

3. Управление:

   * событиями
   * клубами
   * чатами

4. Технический контроль:

   * файлы
   * медиа
   * права доступа

---

# ДОПОЛНИТЕЛЬНЫЕ ИДЕИ (ЗАКРЕПЛЕНЫ В ТЗ)

* Администратор **может удалять некомпетентный контент**
* Главная страница — **карточный UI**
* Расписание — **календарный формат**
* Всё описание написано **для Cursor AI**, без абстракций
