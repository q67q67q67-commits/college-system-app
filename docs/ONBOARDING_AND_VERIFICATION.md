# Ознакомление с проектом и проверка (Narxoz College — NC)

Документ для новых участников и проверки работоспособности системы. Читать **перед** началом работы с проектом.

---

## 1. Что это за проект

**Narxoz College (NC)** — мобильное и веб-приложение для студентов и сотрудников колледжа НАРХОЗ (Казахстан).

- **Функции:** журнал оценок, расписание, форум, чаты, библиотека, события/новости, файлы (2 ГБ на пользователя), профили, профиль директора («Twitter-стиль»).
- **Роли:** Студент, Преподаватель, Директор, Админ.
- **Стек:** Backend — Go, БД — PostgreSQL, Frontend — **Flutter** (мобильная + веб) и **веб-прототип** (HTML/CSS/JS) в папке `web/`.

Подробнее: **`context.md`** (разделы 1–3, 6–7).

## 3. Как запустить и проверить

### Шаг 1: База данных и API

Из **корня репозитория** (где лежат `go.mod` и `docker-compose.yml`):

```bash
docker compose up -d
go run ./cmd/api
```

В логе должно быть: `api: listening on :8080`.

- API: **http://localhost:8080**
- Корень API: `GET /` → текст «NC API. Prototype: /app/»

### Шаг 2: Веб-прототип (браузер, ПК и мобильный вид)

1. Откройте в браузере: **http://localhost:8080/app/**
2. Войдите, например: **student1@nc.kz** / **password123**
3. Проверьте разделы: Главная, Расписание (кнопка «ДЗ и материалы» у пар), Оценки, Библиотека, Форум (темы и ответы), События, Мои файлы, Чат, Профиль директора, Регламент, Карта, Профиль (смена пароля/телефона).
4. Уменьшите ширину окна или откройте с телефона — должна появиться **нижняя навигация**.
5. Выйдите и войдите под **teacher1@nc.kz** — появятся разделы «Группы», «Выставить оценку», «ДЗ к парам».
6. Войдите под **director@nc.kz** или **admin@nc.kz** — на странице «События» должны быть кнопки «Добавить» и «Удалить».

### Шаг 3: Flutter (мобильная и веб-версия)

1. Установите [Flutter SDK](https://flutter.dev/docs/get-started/install) (3.0+).
2. Из корня репозитория убедитесь, что API и БД запущены (шаг 1).
3. Перейдите в папку Flutter-приложения и запустите:
   ```bash
   cd nc_app
   flutter pub get
   flutter run -d chrome
   ```
   Или для мобильного эмулятора:
   ```bash
   flutter run -d android
   ```
   Для Android-эмулятора, если API на ПК:  
   `flutter run -d android --dart-define=NC_API_URL=http://10.0.2.2:8080`
4. В приложении: войти **student1@nc.kz** / **password123**, пройти по разделам (Главная, Расписание, Оценки, Библиотека, Форум, События, Файлы, Профиль директора, Регламент, Карта, Профиль).
5. На широком экране (веб) — боковая панель (NavigationRail), на узком — нижняя панель (BottomNavigationBar).

Подробнее по Flutter: **`nc_app/README.md`**.

## 5. Чек-лист проверки (баги и недостатки)

Имеет смысл пройти после каждого крупного изменения.

- [ ] **Логин:** вход по email/пароль, при неверных данных — сообщение об ошибке.
- [ ] **Роли:** у студента нет «Группы»/«Выставить оценку»/«ДЗ к парам»; у админа нет «Профиль директора».
- [ ] **Главная:** список событий/новостей загружается.
- [ ] **Расписание:** список по дням; в веб-прототипе «ДЗ и материалы» по каждой паре открываются.
- [ ] **Оценки (студент):** список оценок и GPA.
- [ ] **Группы (преподаватель):** список групп, по клику — список студентов.
- [ ] **Выставить оценку (преподаватель):** выбор группы → студент → предмет → оценка → дата → сохранение.
- [ ] **ДЗ к парам (преподаватель):** список занятий, добавление/удаление ДЗ к занятию.
- [ ] **Библиотека:** поиск книг, бронирование.
- [ ] **Форум:** список тем, открытие темы с ответами, новая тема и ответ (в т.ч. анонимно).
- [ ] **События:** список; у директора/админа — добавление и удаление; фильтры по дате и поиску (веб).
- [ ] **Мои файлы:** список, квота, загрузка и удаление файла.
- [ ] **Чат (веб):** WebSocket, отправка/получение сообщений.
- [ ] **Профиль директора:** данные директора и кнопка «Написать директору».
- [ ] **Регламент / Карта:** статические страницы открываются.
- [ ] **Профиль:** смена пароля и/или телефона (PUT /api/profile).
- [ ] **Выход:** очистка токена и переход на экран входа.
- [ ] **401:** при истечении/неверном токене веб-прототип и Flutter перенаправляют на вход (Flutter — через onUnauthorized).

## 6. Известные ограничения

- **Личные и групповые чаты:** в API реализован только общий чат (один WebSocket). Личные/групповые чаты требуют доработки бэкенда.
- **Комментарии к событиям:** в API нет; в интерфейсе не реализованы.
- **Папки в «Мои файлы»:** API отдаёт плоский список; папки/портфолио не реализованы.
- **Профиль директора «Twitter»:** реализованы шапка (имя, контакты, кнопка «Написать директору»). Посты и закреплённые посты требуют отдельного API/модели.
- **Язык интерфейса:** переключение языка не реализовано (в БД есть поле `language` у пользователя).
- **Оповещения:** пуш-уведомления не реализованы.

**Соответствие Заметке (Заметки.md):** Flutter — фронтенд (мобильная + веб), Go — бэкенд, PostgreSQL — БД; роли Студент/Преподаватель/Директор/Админ; навигация Главная/Учебный процесс/Социум/Профиль (и Учебная нагрузка для препода); журнал, расписание, ДЗ, GPA, регламент, библиотека, форум (с анонимностью), чат (общий), карта, события, профиль директора («Twitter»-стиль), файлы 2 ГБ, смена пароля/номера. Реализовано в веб-прототипе и Flutter. Не реализовано: личные/групповые чаты, комментарии к событиям, папки в файлах, посты директора с закреплением, переключение языка, пуш-уведомления — см. раздел 6 «Известные ограничения».
